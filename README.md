# Decode Computation︰ Hands-On Formal Languages and Algorithms – Free Online Textbook

Welcome to the official GitHub repository for the **Decode Computation︰ Hands-On Formal Languages and Algorithms**.
This repository hosts the openly accessible materials for the course, including:

* Jupyter notebooks for each chapter
* The compiled HTML textbook
* Supporting scripts and resources

All publicly accessible content is licensed for open educational use.

---

## 📚 About This Textbook

This textbook is designed to support CS 4110 (Formal Languages and Algorithms) and provides:

* Concept explanations with examples
* Interactive Jupyter notebook exercises
* Practice problems
* Supplementary materials for deeper understanding

The content is organized to support both self-study and classroom instruction.

---

## 📁 Repository Structure
This repository contains the Jupyter notebooks used in the CS 4110 textbook. To access the HTML version of the textbook, visit:[CS 4110 Textbook (HTML)](https://yzhangweber.github.io/cs4110-jupyterbook/intro.html)
